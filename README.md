# 北區國中分佈與佔有率地圖 (115學年度)

🔗 **線上互動網頁**：[https://michaelhe0914.github.io/school-map/](https://michaelhe0914.github.io/school-map/)

## 功能特色
- **全區 389 所北區國中標記總覽**：涵蓋基隆市、臺北市、新北市、桃園市、新竹市、新竹縣、苗栗縣、宜蘭縣、花蓮縣、金門縣、連江縣。
- **多維度即時篩選**：支援關鍵字搜尋（校名、行政區、地址、經銷商）以及「負責業務」、「縣市別」、「經銷商」下拉篩選。
- **多圖層切換**：內建 Google 標準街道地圖、Google 衛星混合實景圖、內政部臺灣通用電子地圖、OpenStreetMap。
- **單校實景定位與導航**：可切換至頁面內嵌 Google Maps 實景定位檢視，或一鍵開啟 Google Maps 導航。
